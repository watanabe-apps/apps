Special Needs Education • Cognitive UI Architecture

特別支援教育におけるWebアプリケーション開発の実際

【本ハンドブックの目的】
知的障害や発達障害を伴う児童生徒が、余計な操作の負担なく学習そのものに没頭できるようにするためのUI/UX設計指針と、学校現場で絶対に破綻させないための開発・運用ノウハウをまとめた実践書です。

📚 理論・設計各章

教育的背景や認知特性から、言葉に頼らない構造化、学校の制約への対策までを詳しく解説しています。
