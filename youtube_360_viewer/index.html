💡 プロジェクターでの投影方法

【接続方法】
iPadを有線（HDMI）またはAirPlayでプロジェクターに接続し、iPadのコントロールセンターから「画面ミラーリング」を選択してください。

【なぜ歪まないのか】
通常のYouTubeアプリだと「ビデオ出力モード」になり、360度が展開された平面パノラマ映像が送られてしまいます。このビューアーはWeb画面ごとミラーリングするため、iPad手元の360度映像がそのままプロジェクターに映ります。

【操作方法】
・画面ドラッグ / スワイプ：画面上のどこでもドラッグ・スワイプして自由に見渡せます（慣性付き）。
・画面タップ：動画の再生 / 一時停止を切り替えます。
・ズーム（画角）：スライダー、マウスホイール、またはiPadの2本指ピンチでズーム可能。
・🎯 正面リセット：いつでも最初の正面の向きに戻せます。
・📱 ジャイロ：iPad本体を向けた方向に映像が連動します。
・🔄 自動回転：ゆっくり周囲を360度見回す上映モードです。
・👁️ UI非表示：右上のボタンで操作枠を隠して大画面上映できます。

⚠️ エラー153の原因：直接ファイルを開いています

現在アドレスバーが file:///... になっています。
YouTubeのセキュリティ仕様により、ローカルのHTMLファイルを直接ダブルクリックして開くと動画の再生がブロック（エラー153）されます。

【解決方法】Webサーバー経由で開いてください：
① Macの場合: ターミナルで python3 -m http.server 8000 を実行し、
http://localhost:8000/youtube_360_viewer/ で開く
② iPadの場合: Macと同じWi-Fiから
http://[MacのIP]:8000/youtube_360_viewer/ で開く
③ GitHub Pagesにpush して公開URLで開く
